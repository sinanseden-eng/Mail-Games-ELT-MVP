# Penalty Shootout 0.9G2 — True On-Pitch Action Replay

## Objective

Replace the 0.9G1 result-tableau presentation with a readable football sequence. The realistic selection scene remains unchanged, but a resolved kick now proceeds through four full-frame phases:

1. realistic run-up and boot contact;
2. clean goal-facing ball-flight camera;
3. full-screen goalkeeper action matched to the stored dive;
4. outcome-specific net, glove or miss camera.

## Key changes

- The ball is visibly animated from contact to the chosen coordinate.
- The foreground striker no longer blocks the flight camera.
- Goalkeeper action is no longer shown in a small inset.
- Goal, save and miss use their dedicated full-screen images through the final frame.
- Left-side results mirror the action camera while right-side results retain the original composition.
- Goal impacts bend local net strands instead of drawing a circular target/radar graphic.
- The large result banner appears only after the action has resolved.

## Preserved systems

Question validation, secret choices, deterministic resolution, scoring, Gmail delivery, signed links, Supabase data, Turkey Fight and Sniper remain unchanged.
