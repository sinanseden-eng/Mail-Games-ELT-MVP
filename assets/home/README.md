# Main-page collection poster

`three-games-poster.webp` is promotional artwork, not a gameplay screenshot.
Generated with the built-in image-generation tool and optimized to WebP. The
page overlays accessible HTML titles and buttons; teaser dialogs render the
actual Football, Tanx and Sniper code. No game rules or terrain were changed.

Production prompt: A wide 2:1 cinematic illustrated cover for Mail Games ELT,
exactly three equally prominent blended scenes: a red-shirted penalty taker
and yellow-clad diving keeper in a floodlit stadium; widely separated tanks
on natural rocky hills against a stormy neon industrial city; a fully clothed
fictional training scout overlooking an abandoned village with cover. Teal
shadows and amber lighting, quiet dark upper area for HTML headings. No text,
logos, UI, gore, injuries, turkey characters, maglev trains or tower-mounted
tanks. Subjects readable at thumbnail size. Game key art rather than gameplay.
