# Football player assets

These are optimized copies of Sinan's supplied Meshy goalkeeper and shooter from Football Animation Lab v3. Embedded 4096-pixel textures were reduced to 512-pixel JPEGs; skin weights, skeletons and mesh geometry were preserved. Downloads total 3,462,024 bytes instead of 41,310,684 bytes.

The keeper uses the Lab's directional IK choreography, extended for all nine goal targets. Its raw overhead jump / backward-roll clips are excluded from playback. The shooter keeps the original `Kick_a_Soccer_Ball` clip. Unreferenced animation buffers remain in the GLBs; no decoder or external texture download is required.
